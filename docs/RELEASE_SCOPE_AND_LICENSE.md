# Review-stage sharing boundary

The current source repository is public, while a separate Anonymous GitHub mirror provides the URL included in the double-anonymous manuscript. Public availability of text/code is **not** a license to reuse third-party datasets, annotations, models, or other materials. The repository currently has no explicit outbound reuse license; permission for reuse should not be assumed.

All released numeric files are precomputed/derived aggregate summaries and not full source-level task records. Scripts are independent review aids. Original images, enhanced images, original provider annotations, third-party weights and source trees, unpublished identifying manuscript materials, unredacted experimental logs, and direct author contact paths are intentionally excluded. Do not add these assets through README links, raw GitHub links, Git LFS, release archives, submodules or issue attachments without a review of origin, redistribution rights, and anonymity.

The source GitHub owner's identity and the local commit metadata are different from the content of the 4open mirror. Reviewers must be directed to the anonymous URL, never the identifiable original repository. Always test the anonymous URL in a signed-out private/incognito session after refreshing the mirror, including the repository ZIP download and all file names. Recheck the mirror expiration choice before the review period ends; expiry redirection to the original GitHub can reveal authors.

Review-stage documentation updates are versioned. No post-submission change should silently reinterpret the reported frozen experiments or imply that newly generated plots are the original paper figures.
